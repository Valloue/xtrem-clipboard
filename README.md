# Xtrem Clipboard

Historique de presse-papiers pour Windows — alternative Fluent à Win+V.

**Dépôt :** https://github.com/Valloue/xtrem-clipboard (public)

**Statut :** cadrage / démarrage (pas encore d’application compilable).

## Stack

- C# · WinUI 3 · .NET 8 · Windows App SDK
- Unpackaged, self-contained x64
- Windows 10 version 1809+

## Fonctionnalités prévues (V1)

- Historique **texte** + **images**
- Épingler, rechercher
- Raccourci global configurable
- Stockage local (LocalAppData) — pas de cloud
- Exclusions / vie privée (pas de log du contenu clipboard)
